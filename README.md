## 🎯 Objetivo del repositorio

Centralizar los trabajos prácticos, ejercicios, proyectos y desarrollos correspondientes al cuarto semestre de la carrera, manteniendo un espacio organizado para compartir código, documentar avances y trabajar colaborativamente.

- CSS3
- JavaScript
- Python
- Java

- SQL y bases de datos
- React y otras herramientas del ecosistema de desarrollo web.

## 📁 Organización

El repositorio se organiza en directorios según las materias, tecnologías y proyectos trabajados durante el cursado.

Cada carpeta puede contener su propio README con instrucciones, dependencias y documentación específica.

## 🌿 Flujo de trabajo

Para mantener una organización colaborativa:

- `main`: rama principal, destinada a conservar las versiones integradas y estables.
- `Prueba`: rama de desarrollo e integración de cambios.

Se utiliza Git para el control de versiones y GitHub para compartir el código y coordinar el trabajo.

## 🚀 Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

Ingresar a la carpeta:

```bash

```
